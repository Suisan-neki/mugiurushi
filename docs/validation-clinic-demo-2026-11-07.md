# 架空の診療所アプリで、照合から試験の実行・修正用プロンプトまでを通した記録（2026年11月7日）

今回の検証では、架空の診療所アプリ（`examples/clinic-tasks`）を対象に、mugiurushi の画面で次の流れを通した。

ガイドラインとの照合 → 検証案の了承 → 試験の設定と実行 → 結果の確認 → 結果と根拠を含む修正用プロンプトの表示

- 照合と試験の案は、実際の mugiurushi-ai と実際のモデル（`gpt-6.1-terra`）で作った。
- 試験は、mugiurushi の既存の実行基盤（local方式）で、架空のアプリを実際に起動して実行した。合成の結果は使っていない。
- 試験の設定（起動対象・引数・保存先・読み直し・判定条件）と、確かめる項目と判定条件の対応づけは、案から自動では作っていない。人が設定画面で入力する操作を、スクリプト（`tools/clinic-demo.mjs`）が決まった規則で入力した。

## 確認できたこと・できていないこと

- 確認できた：照合から修正用プロンプトまでを、実際のモデルと実際の試験の実行で通せること。設定画面に了承した案が出て、結果の画面との間を行き来できること。
- 合成の試験（`tools/flow-smoke.mjs`）で確認した：実行していない試験を「未実行」とだけ示し、成功・失敗として数えないこと。実行したが判定条件に対応づけていない部分を「未確認」として理由を添えて示すこと。案の合格の条件から判定条件の下書きを作れること。
- 確認していない：試験の案から試験の設定を自動で作ること（作っていない）。今回の対応づけは、照合の候補の文に含まれる語で決まった規則を使っており、人が判断した対応づけではない。候補と案の中身の良し悪し。修正した版での再試験（6）を実際の実行で通すこと（合成の試験でだけ確かめた）。

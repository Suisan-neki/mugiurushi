# 架空の診療所の連絡タスク管理（デモ用）

mugiurushi の「ガイドラインの照合から試験・修正・再試験まで」の流れ（`/flow`）を、実際に試験を実行して見せるための架空のアプリ。実在の診療所・患者・職員のデータは扱わない。

- 職員がコマンドで患者ごとの連絡タスクを追加し（`add`）、一覧で読み直す（`list`）。
- 最初の版は、担当外の職員も一覧を読め、患者の情報への操作を記録せず、保存するファイルの名前を外から指定できる。
- `tools/clinic-demo.mjs` が、この版と、閲覧範囲と操作の記録を直した版の2つのコミットを持つ架空のリポジトリ `example/clinic-tasks` を手元に作る。
